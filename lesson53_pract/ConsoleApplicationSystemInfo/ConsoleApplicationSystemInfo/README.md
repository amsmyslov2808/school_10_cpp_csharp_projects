# Информация о компьютере — учебный пример

Простой консольный проект C++ для Windows: вся программа находится
в `ConsoleApplicationSystemInfo.cpp`, в одной функции `main`.
Используются переменные, условия `if`, цикл `for` и вывод `cout`.
Функции из `Windows.h` получают сведения у операционной системы.
Сложная работа с WMI и сторонние библиотеки не нужны.

## Что показывает

- Имя компьютера, число логических процессоров и архитектуру.
- Общий и доступный объём памяти, её загрузку.
- Разрешение и частоту основного монитора.
- Размеры разделов жёстких дисков и свободное место.
- Время работы и заряд батареи, если она есть.

Для простоты убраны модели оборудования, BIOS и сеть.
Разделы C: и D: могут находиться на одном физическом диске.
ГиБ — 1024³ байт. Быстрый запуск Windows может сохранять время работы
между выключениями. Число логических процессоров не равно числу физических ядер.

## Как запустить

Откройте `ConsoleApplicationSystemInfo.vcxproj` в Visual Studio с компонентами
разработки на C++ и Windows SDK. Выберите **Debug / x64** и нажмите **Ctrl+F5**.
Проект использует набор инструментов `v145`.

Готовая программа: `x64\Debug\ConsoleApplicationSystemInfo.exe`.
Код и вывод используют UTF-8 (опция `/utf-8` уже включена в проекте).

## Что означают непривычные записи

- `SYSTEM_INFO`, `MEMORYSTATUSEX` и другие структуры — наборы данных Windows.
- `{}` при создании структуры заполняет её поля нулями.
- `&memory` передаёт адрес: функция Windows записывает данные в эту структуру.
- `sizeof(memory)` — размер структуры в байтах.
- `nullptr` — отсутствие адреса, здесь выбор монитора по умолчанию.
- `QuadPart` — поле с большим целым числом байт.
- `%` — остаток от деления, используется для вычисления минут.
- `power.BatteryFlag & 128` проверяет признак отсутствия батареи.
